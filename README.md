### Portal for Academia - Industry Collaboration for Skill Mapping, Internships, and Placement

## 🌿 About the Project
**AYUSH-SETU** is a responsive, mobile-first web application purpose-built for the **Ministry of Ayush (Ayurveda, Yoga & Naturopathy, Unani, Siddha, Homeopathy)**, Government of India. 

Unlike generic software/IT job boards, AYUSH-SETU exclusively caters to the **Ayush clinical, herbal pharmaceutical, FMCG (e.g., Dabur, Himalaya, Patanjali, Baidyanath, Charak, Kottakkal), botanical supply chain, and regulatory ecosystem**. It introduces the **Ayush Digital Dossier**, replacing generic tech resumes with verified clinical procedure logs, Schedule T GMP formulation batches, and laboratory instrumentation proficiencies.

---

## 🏛️ Key Stakeholder Modules & Dashboards

1. **Student / Scholar Dashboard**:
   - Tailored for BAMS, BHMS, BUMS, BSMS, M.Pharma (Ayush), and Biotechnology students.
   - Track verified clinical hours (520+ hrs), Schedule T GMP formulation batches, and state council licensing.
   - 1-Click apply with cryptographically verified Ayush Digital Dossiers.

2. **Academic Institution Dashboard**:
   - Institutional portal for College Placement Cells & Academic Deans (e.g., All India Institute of Ayurveda - AIIA).
   - **Student Practical Credential Endorsement Queue**: Review submitted clinical rotations and analytical runs with 1-click digital sign-off.
   - **Institutional MoU Management**: Bilateral training quotas and joint research projects with industry leaders.

3. **Industry Partner Dashboard**:
   - For Ayush pharma & FMCG recruiters (Himalaya Wellness, Dabur India Ltd, Patanjali, Charak).
   - Review incoming candidate dossiers with verified equipment proficiencies (HPLC, HPTLC, AAS) without credential fraud.
   - Post vacancies and corporate R&D bottleneck challenges.

4. **Ministry Admin Dashboard**:
   - National Directorate overview under Ministry of Ayush & NCISM.
   - **State-by-State Ayush Skill-Gap Heatmap**: Interactive map highlighting surplus vs critical shortage domains across 10+ states.
   - Macro analytics: National placement rates, active MoUs, and bridge course completions.

## 🔬 Core System Features

- **Ayush Digital Dossier**:
  - Verified Clinical Logbook (Panchakarma cases: Virechana, Shirodhara, Basti).
  - Schedule T GMP Formulation Batches (Chyawanprash, Asava-Arishta, Bhasma calcination).
  - Laboratory Instrumentation Proficiencies (HPTLC, AAS Heavy Metals, UV-Vis).
  - 6-Axis SVG Domain Competency Radar Chart vs National Industry Benchmarks.
  - State Ayush Council Verified Badge with interactive QR verification.

- **Automated Skill-Mapping & Dynamic Bridge Engine**:
  - Real-time match score calculation against industry job descriptions.
  - Automatically isolates missing competencies (e.g., *Heavy Metal AAS Testing*).
  - Recommends free, accredited CCRAS & AYUSH-SWAYAM bridge modules with instant score simulation.

- **Industry-Academia R&D Challenge Marketplace**:
  - Sponsored industrial technical bottlenecks with funded grants (₹9.5L - ₹22L).
  - Multi-step proposal submission workflow for faculty PIs and PG scholars.

- **Internship & Placement Portal**:
  - Categorized filters: *Quality Control & Testing, Formulation R&D, Botanical Sourcing & GACP, Clinical Residencies, Regulatory Affairs (ASU)*.
  - One-click application with verified dossier snapshot transmission.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer)
- npm or yarn

### Installation & Local Run

1. Clone the repository:
   ```bash
   git clone https://github.com/atul110106/ayush-setu.git
   cd ayush-setu
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
